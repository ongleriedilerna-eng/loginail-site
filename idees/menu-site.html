Le menu des sites

Les trois traits en haut à droite, sur tous les sites. Touchez-les pour ouvrir le menu, puis une rubrique pour y aller. C'est le vrai site de Cerise : le menu prend tout seul les couleurs et l'écriture de chaque style.

Dans les deux versions

  • Les rubriques : Accueil, Prestations, Avis, À propos, Bon à savoir, Infos pratiques (horaires et accès). Une rubrique vide chez une prothésiste disparaît du menu.
  • Réserver : un vrai bouton plein en bas du menu, pas une ligne de plus.
  • Mentions légales : tout en bas, en petit (obligatoire par la loi).
  • Les trois traits : dans une petite pastille claire, pour rester lisibles sur tous les fonds, même chargés.
  • Sur ordinateur : le site s'affiche dans un téléphone au milieu de l'écran, donc c'est exactement le même menu.
