Les questions fréquentes

Comment me connecter à l’appli ?
Tapez l’adresse e-mail de votre compte : vous recevez un code par e-mail, sans mot de passe.

Comment récupérer mes clientes ?
Dans l’appli : Réglages › Importer mes clientes, depuis les contacts de votre iPhone ou un fichier Excel.

Comment fermer mon salon pour les vacances ?
Agenda › le rond barré en haut › choisissez du… au….

Comment changer mon site ?
Dans l’appli : Mon site › Personnaliser mon site.

Comment supprimer mon compte ?
Dans l’appli : Réglages › Supprimer mon compte. Tout est effacé, pour toujours.
